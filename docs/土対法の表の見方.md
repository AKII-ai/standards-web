# 土対法の表の見方

土壌汚染対策法の基準値を、物質ごとに横へ並べて見る機能の説明です。
プログラムの知識は不要です。数値の意味や、現場でどう使うかは法令の原文を見てください。この説明は「画面の表がどう並ぶか」だけです。

## 開く法令

緑になるのは **土壌汚染対策法施行規則** です。

「土壌汚染対策法」や「土壌汚染対策法施行令」を開いても、この横並びの表にはなりません。法律と施行令には、このアプリが拾う数値の表が無いためです。検索欄に「土壌汚染対策法施行規則」と入れるか、「よく使うもの」の同じ名前を選びます。

公開サイトは https://akii-ai.github.io/standards-web/ です。自分のパソコンで見るときは、`web` フォルダで `npm run dev` を実行し、http://localhost:5173 を開きます。

## 画面に出る表

1つの行が1つの物質です。左から次の順です。

| 列 | 意味 |
|---|---|
| 分類 | 第一種・第二種・第三種のどれか |
| 特定有害物質の種類 | 物質の名前 |
| 土壌溶出量基準（mg/L） | 土壌を水に溶かしたときの基準 |
| 土壌含有量基準（mg/kg） | 土壌に含まれている量の基準 |
| 地下水基準（mg/L） | 地下水の基準 |
| 第二溶出量基準（mg/L） | 第二溶出量の基準 |

物質の並びは、第一種（クロロエチレンからベンゼンまで）→ 第二種（カドミウムからほう素まで）→ 第三種（シマジンから有機りん化合物まで）です。

表は施行期間ごとに分かれています。上にあるほど新しい期間です。見出しは「施行 2026-07-01 〜 現行」のような形です。e-Gov に残っている版だけなので、おおむね 2017 年より前はこのアプリでは出ません。

表の上と下に「Excel出力」と「Markdown出力」があります。「基準値のみ」か「変更内容を追記」を選んでから押します。Excelは改正の年ごとにシートが分かれ、シート名は「年」と「法令名」です。シートの列は画面と同じです。Markdownは年ごとのファイルをZIPにまとめて保存します。変更内容を追記すると、変わった基準値に旧値からかっこ書きが付きます。

ページの幅は、ブラウザのウィンドウに合わせて広がったり狭まったりします。表の中の縦線（列の境目）をドラッグすると、その列の幅が変わります。施行期間が複数あっても、同じ列は揃います。一覧に戻ると、列の幅は元に戻ります。

## 記号の意味

- 黄色く塗ったセルは、1つ前の版と比べて追加または変更があった物質です。分類、物質名、変わった基準値に付きます。変わった基準値のセルには、赤い文字で変更前の値がかっこ書きされます。新しく入った物質は「（この版で追加）」と書きます。
- **－** は、その物質とその列の組合せが、その版の別表に無い、という意味です。
- **（物質名 はこの版で廃止）** は、前の版にはあった物質が、その版ではなくなった行です。
- 「検出されないこと」や「かつ」を含む長い文は、数値に置き換えず、条文の言い方のまま出します。

## 2019年4月で別表の番号がずれていること

法令のうしろについている「別表第一」「別表第二」などの番号は、2019年4月1日を境に中身がずれています。画面の列名は番号ではなく、意味の名前（土壌溶出量基準、など）にそろえています。だから、2019年の前と後を見比べても、同じ列は同じ種類の基準です。

2019年4月1日より前:

| 別表 | 画面の列 |
|---|---|
| 別表第一 | 地下水基準 |
| 別表第二 | 第二溶出量基準 |
| 別表第三 | 土壌溶出量基準 |
| 別表第四 | 土壌含有量基準 |

2019年4月1日以降:

| 別表 | 画面の列 |
|---|---|
| 別表第二 | 地下水基準 |
| 別表第三 | 第二溶出量基準 |
| 別表第四 | 土壌溶出量基準 |
| 別表第五 | 土壌含有量基準 |

この期間の別表第一は物質の一覧で、基準値の列には使いません。措置の方法などが書いてある別表も、この横並びの表には入れません。

## 並びが指定と違う年

2018年4月1日より前の版は、物質の呼び方が今の指定と違います（例: 「一・二―ジクロロエチレン」ではなく「シス―一・二―ジクロロエチレン」）。その年は、指定した順番を使わず、法令データが返した順番で出します。表の下に「この版の並び順はAPI取得結果の順」と出ます。

## この表に入らないもの

- 告示（測り方の細かい定めなど）と、市区町村の条例
- e-Gov に無い、おおむね 2017 年より前の古い改正
- 汚染土壌の搬出や処理の基準など、施行規則のこの4種類以外の表

表に無いから、規制が無いわけではありません。

## 並びを自分で直す

数値はこのファイルに書きません。アプリは毎回 e-Gov から数値を取り、ファイルは「どの列か」「どの別表か」「物質をどの順で出すか」だけを持っています。

ファイルの場所:

`web/src/layouts/414M60001000029.md`

中は3つの部分です。

1. **列** … 左から右への列の名前と単位。行の順番が、画面の左から右になります。
2. **別表** … 「この日付以降は、この列を、この別表から取る」。日付が空の行は、それより古い期間用です。
3. **第一種・第二種・第三種** … 見出しが「分類」になり、その下の物質の順番が行の順番になります。物質名は、法令が「以下「○○」という。」と短く呼んでいる名前に合わせます。

直したあとは `web` フォルダで `npm run dev` を再実行し、施行規則を開き直します。並びの確認だけなら `npm run check-matrix` です。

公開サイトに反映するには、変更を `main` に push します。手元のファイルを保存しただけでは、公開URLは変わりません。

## 別の法令でも同じ表にしたいとき

`web/src/layouts/` に、法令IDと同じ名前の Markdown を足します。法令IDは、その法令を開いた画面の「法令ID」に出ています。中身の形は、上の土対法のファイルと同じにします（列、別表、物質のグループ）。

そのファイルが無い法令は、今までどおり「表/条・項目・条件・基準値」の縦の表のままです。
