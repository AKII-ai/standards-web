# 基準値（ブラウザ版）

e-Gov 法令API で法令を検索し、別表と号列記から基準値の表を出します。
ログインは不要です。URL が分かれば使えます。

公開URL: https://akii-ai.github.io/standards-web/

出典は e-Gov 法令API のみです。告示・条例は API に無いので出ません。

## 使い方

1. 最初の画面の「よく使うもの」から選ぶか、上の欄で検索する（例: 大気、土壌、地下水）。
2. 法令を開くと、別表と号列記の基準値を施行期間ごとに表にする。
3. 「法令一覧に戻る」で、直前の検索結果に戻る。検索欄の文字は消さない。
4. 検索欄を空にすると、最初の画面に戻る。
5. 表が出ていれば「Excel出力」。改正（施行）年ごとにシートが分かれ、シート名は `{年} {法令名}`。

「大気法」のように略した名前でも、近い法令名を出します。AI は使っていません。

## 緑色の「基準値あり」

一覧のうち、別表または号列記から基準値の行が1つでも取れた法令を緑にします。
判定は現行の条文だけです。開くときは収録されている改正版を全部取ります。

号列記をどの条から拾うかは、単位の言い回しで決めています。

- ファイル: [`src/extract/unit_hints.txt`](src/extract/unit_hints.txt)
- 1行1語。`#` で始まる行はコメント
- ミリグラムなどの日本語と、mg/L・ppm などの記号を書いてある
- アプリ実行中にネットへ単位を取りに行かない。語を足すときはこのファイルを編集する

別表は、単位語が無くても行があれば取り出します。

## 含まれないもの

- 告示・条例（地下水の環境基準告示など）
- e-Gov に無い古い改正版（多くの法令で概ね 2016〜2017 年より前）
- 別表でも号列記でもない、地の文だけの基準

表に無いから規制が無い、ではありません。

## ローカルで開く

```powershell
npm install
npm run dev
```

http://localhost:5173 を開く。

GitHub Pages へ出すときは `main` に push する。Actions が `dist` を公開する。
