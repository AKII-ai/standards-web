# 基準値（ブラウザ版）

e-Gov 法令API で法令を検索し、別表と号列記から基準値の表を出します。
ログインは不要です。URL が分かれば使えます。

公開URL: https://akii-ai.github.io/standards-web/

出典は e-Gov 法令API のみです。告示・条例は API に無いので出ません。

## 使い方

1. 最初の画面の「よく使うもの」から選ぶか、上の欄で検索する（例: 大気、土壌、地下水）。
2. 法令を開くと、別表と号列記の基準値を施行期間ごとに表にする。
3. 「法令一覧に戻る」で、直前の検索結果に戻る。検索欄の文字は消さない。
4. 検索欄を空にすると、最初の画面に戻る。
5. 表が出ていれば「Excel出力」。改正（施行）年ごとにシートが分かれ、シート名は `{年} {法令名}`。

「大気法」のように略した名前でも、近い法令名を出します。AI は使っていません。

## 追加機能はプログラムで動かしています

検索、条文からの抜き出し、新旧の比較は、どれもプログラムの処理です。AI は使っていません。

数値は e-Gov の条文から抜きます。アプリが覚えた値や、解説サイトの値は使いません。

法令を開くと、収録されている改正版を全部取ります。施行日の新しい版と、ひとつ前の版をプログラムが突き合わせます。

- 土対法の横並びの表は、同じ物質の同じ列（土壌溶出量、含有量、地下水、第二溶出量）の文言を比べます。
- ほかの法令の縦表は、表名・項目・条件が同じ行の条文の文言を比べます。

画面の黄色は、追加または変更があった物質です。基準値セルの赤いかっこ書きは、プログラムが出した「旧 → 新」（新しく入ったときは「この版で追加」）です。

比較できるのは、e-Gov に残っている版のあいだだけです。多くの法令で、おおむね 2017 年より前は比べられません。

## 緑色の「基準値あり」

一覧のうち、別表または号列記から基準値の行が1つでも取れた法令を緑にします。
判定は現行の条文だけです。開くときは収録されている改正版を全部取ります。

号列記をどの条から拾うかは、単位の言い回しで決めています。

- ファイル: [`src/extract/unit_hints.txt`](src/extract/unit_hints.txt)
- 1行1語。`#` で始まる行はコメント
- ミリグラムなどの日本語と、mg/L・ppm などの記号を書いてある
- アプリ実行中にネットへ単位を取りに行かない。語を足すときはこのファイルを編集する

別表は、単位語が無くても行があれば取り出します。

## 物質×基準の並び（土対法など）

法令ごとに `src/layouts/{法令ID}.md` があると、縦表ではなく物質ごとの横並びの表で出します。
値は MD に書きません。列名・別表の対応・物質の順番だけです。

今あるのは土壌汚染対策法施行規則（`414M60001000029.md`）です。見方と直し方は [土対法の表の見方](docs/土対法の表の見方.md) に書いてあります。別の法令も同じ形のファイルを足せば使えます。

ページの幅は、ブラウザのウィンドウに合わせて広がります。表の中の縦線をドラッグすると、その列の幅が変わります。

## 含まれないもの

- 告示・条例（地下水の環境基準告示など）
- e-Gov に無い古い改正版（多くの法令で概ね 2016〜2017 年より前）
- 別表でも号列記でもない、地の文だけの基準

表に無いから規制が無い、ではありません。

## ローカルで開く

作業フォルダは `web` です。親フォルダでは動きません。

`npm run` だけだと、名前の一覧が出るだけで何も起動しません。後ろにスクリプト名を付けます。

```powershell
cd web
npm install
npm run dev
```

`npm install` は最初の一回だけです。`npm run dev` のあと http://localhost:5173 を開きます。止めるときはその画面で `Ctrl+C` です。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発用サーバ（普段はこれ） |
| `npm run build` | 公開用の `dist` を作る |
| `npm run preview` | 作った `dist` を確認する |
| `npm run check-extract` | 抽出の確認 |
| `npm run check-fuzzy` | あいまい検索の確認 |
| `npm run check-matrix` | 土対法マトリクスの確認 |

GitHub Pages へ出すときは `main` に push する。Actions が `dist` を公開する。
